# Methodology

The condition simulates workshop → elicitation → analysis → architecture/design → implementation backlog → implementation agent.

Boundary controls: starting knowledge equals the YOLO stakeholder brief plus byte-identical website snapshot; canonical FrostLine `docs/` at revision `1732c24654f41849016574a80bc47a10be8090d0` is used only by the simulated SME to answer explicit questions; no `benchmarks/`, scoring material, candidate implementations or evaluation results are used. Discovery is frozen before engineering. Unknowns remain unknown.

`.experiment-audit/` contains source provenance for experiment administrators and is explicitly outside implementation-agent context.
